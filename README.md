# ChordMate 

ChordMate is a multifunctional, self-guided mobile application designed to help beginners learn the guitar through interactive, real-time tools and community support. 

## Features

- **Real-Time Audio Feedback:** Utilizes audio processing to listen to the user play and provide instant visual feedback on chord accuracy.
- **Precision Metronome:** A built-in rhythm training tool to help beginners practice timing, strumming patterns, and transitions seamlessly.
- **Community Forum:** A social space where users can post their own chord renditions to songs, share feedback via comments, and rate helpful posts.

## Tech Stack

- **Frontend & App Logic:** Flutter & Dart
- **Chord classification model:** TFLite
- **Backend/Database:** Firebase Auth and Firestore
